# 丽群电商管理 · 帆布订单统计工具

这是丽群电商管理工作流中的帆布订单统计工具，用于把电商平台导出的帆布订单 Excel 整理成可生产、可核对、可打印的明细表。

当前应用名称：`丽群帆布纺织电商统计系统`

## 主要用途

- 读取帆布订单原始 Excel。
- 自动识别订单号、规格名称、规格编码、数量、快递单号、备注等字段。
- 从规格名称中提取尺寸，例如 `2米*3米`、`2x3米`、`2×3米`。
- 按尺寸分组排序，生成订单明细、小计和总汇总。
- 结合库存数据计算订单数量、库存数量、需加工数量、剩余库存和需加工平方数。
- 自动识别定制或异常尺寸订单，单独生成“异常订单”表。
- 输出适合打印和车间加工核对的 Excel 文件。

## 丽群电商管理场景

这个工具服务于丽群电商日常订单管理，重点解决帆布类商品订单从平台导出后人工整理慢、尺寸统计容易出错、库存与加工数量难核对的问题。

在日常使用中，可以按下面流程处理：

1. 从电商平台导出当天帆布订单 Excel。
2. 打开本工具，选择订单原始文件。
3. 可选填写或导入当前库存数量。
4. 生成整理后的订单明细表。
5. 根据“需加工数量”和“需加工平方数”安排裁剪、加工和发货。

## 运行方式

安装依赖：

```bash
pip install -r requirements.txt
```

启动软件：

```bash
python 帆布订单整理.py
```

## 打包发布

在 Windows 电脑上运行：

```bash
python build_release.py
```

打包结果会生成到 `release/` 目录，文件名类似：

```text
丽群帆布纺织电商统计系统_v1.11.zip
```

## 重要文件

| 文件 | 作用 |
|---|---|
| `帆布订单整理.py` | 主程序，包含订单整理、库存核算、Excel 生成和图形界面 |
| `build_release.py` | 打包发布脚本 |
| `requirements.txt` | Python 依赖 |
| `logo.png` / `logo.ico` | 软件图标资源 |

## 输出内容

生成的 Excel 通常包含：

- 订单明细
- 尺寸分组小计
- 库存核算
- 加工清单
- 异常订单

这些内容用于丽群电商管理中的订单核对、库存判断、生产加工和发货准备。
